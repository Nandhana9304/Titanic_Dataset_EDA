# Titanic Dataset – Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on exploring the Titanic dataset using Python and its data analysis libraries. The objective is to understand the dataset, identify missing values, analyze passenger survival patterns and create meaningful visualizations.

This project was completed as part of the **SkillMe Data Science Virtual Internship – Week 1**.

## Objectives

- Load and explore the Titanic dataset.
- Understand dataset columns and data types.
- Identify missing values.
- Analyze passenger survival rates based on passenger class and gender.
- Create visualizations to understand data patterns.

## Technologies and Libraries Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset Information

The Titanic dataset contains information about passengers aboard the Titanic, including their age, gender, passenger class, fare and survival status.

- Total records: 891
- Data source: Seaborn Titanic dataset

## Exploratory Data Analysis

The following operations were performed:

1. Loaded the Titanic dataset using Seaborn.
2. Inspected the dataset using `head()`, `info()` and `describe()`.
3. Checked missing values using `isnull().sum()`.
4. Analyzed survival rates using `groupby()`.
5. Created a bar chart of survival rates by passenger class.
6. Created a histogram of passenger age distribution.

## Key Findings

- Total passengers analyzed: 891.
- First-class passengers had the highest survival rate of 62.96%.
- Female passengers had the highest survival rate of 74.20%.
- Missing values were identified in the dataset for further cleaning.

## Visualizations

The project includes:
- Survival Rate by Passenger Class.
- Distribution of Passenger Ages.
